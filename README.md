# PlanPro App

Plataforma para entrenadores personales y coaches online: gestión de clientes, planes de alimentación y entrenamiento, seguimiento diario y evaluaciones — con un portal para el cliente final, que es lo que la competencia (Macro, Trainerize, etc.) no ofrece.

## Estructura del proyecto

```
PlanPro-App/
├── docs/
│   ├── propuesta-producto.md    ← propuesta completa: features, precios, roadmap
│   └── fase-0-roadmap.md         ← qué está hecho y qué falta para validar
└── prototype/                     ← prototipo funcional (Vite + React + Tailwind)
    └── README.md                  ← cómo correrlo y desplegarlo
```
